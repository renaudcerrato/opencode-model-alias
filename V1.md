# OpenCode V1 (legacy)

This guide covers OpenCode V1 (1.18.29 or later). For V2 installation and agent bindings, see the [README](README.md). The same package provides separate V1 and V2 plugin implementations.

## Installation

Add the pinned package to `opencode.jsonc`:

```json
{
  "plugin": ["@renaudcerrato/opencode-model-alias@2.1.0"]
}
```

OpenCode installs npm plugin references on startup; no separate npm install is needed for the published package.

<details>
<summary>Install from source</summary>

```sh
git clone https://github.com/renaudcerrato/opencode-model-alias.git ~/workspace/opencode-model-alias
cd ~/workspace/opencode-model-alias
npm ci
```

Then configure the local checkout:

```json
{
  "plugin": ["~/workspace/opencode-model-alias"]
}
```

</details>

## Use aliases in agents and commands

V1 resolves alias names in `agent.*.model` and `command.*.model`:

```json
{
  "agent": { "reviewer": { "model": "cheap" } },
  "command": { "review": { "model": "cheap", "template": "Review the changes." } }
}
```

Agent Markdown frontmatter can also specify an alias:

```markdown
---
description: Review changes
mode: subagent
model: cheap
---
```

Define each machine's targets in `~/.config/opencode/model-aliases.json`:

```json
{
  "cheap": { "model": "openai/gpt-4o-mini", "variant": "max" },
  "reviewer": "cheap"
}
```

String values can name another alias; object values must name a direct `provider/model`. Chains have a 16-hop limit, and a string alias inherits the variant of the nearest object-form target. Alias variants override variants configured on agents or commands. Alias keys shadow identical model references, even when a key looks like `provider/model`.

The file lives at `$OPENCODE_CONFIG_DIR/model-aliases.json` when that variable is set, otherwise `$XDG_CONFIG_HOME/opencode/model-aliases.json`, falling back to `~/.config/opencode/model-aliases.json`. The plugin does not create the file during startup.

## Manage aliases with `/alias`

```text
/alias list
/alias set cheap openai/gpt-4o-mini
/alias set smart ollama-cloud/glm-5.3-flash max
/alias delete cheap
/alias help
```

`/alias set` validates direct models and variants against available provider metadata, rejects cycles and chains deeper than 16 hops, and creates the file if needed. Setting an alias without a variant removes its previous variant. `/alias list` shows full chains and their effective variants. Deleting a referenced alias is refused unless you use `/alias delete <key> force`; force may leave dependent aliases unresolved. Invalid or unreadable alias files cause command errors but do not stop OpenCode from starting.

**Restart OpenCode** after setting or deleting aliases so the config hook picks up the new mappings.

See [Migrate from V1 to V2](README.md#migrate-from-v1-to-v2) for the current config-based approach.
